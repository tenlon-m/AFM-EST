## 简介

AFM-EST (Advanced File Manager with Enhanced Search & Transfer) 是一款现代化的双窗口文件管理器，基于 Qt6 开发，提供丰富的文件管理功能和优化的用户体验。

### 主要特性

- 双窗口文件浏览
- 现代化 Windows 11 风格界面
- 快速访问和收藏夹
- 多种视图模式（详细信息、图标、缩略图、列表、平铺）
- 多种图标尺寸（小、中、大、特大）
- 浅色/深色主题切换
- FTP/P2P 文件传输
- 文件搜索和预览
- 虚拟化渲染（支持10000+文件）
- 缩略图异步加载和缓存

## 快速开始

### 启动程序

双击 `AFM-EST.exe` 或运行 `python AFM-EST.py` 启动程序。

### 基本操作

1. **浏览文件**：使用左右窗格浏览不同目录
2. **切换磁盘**：点击磁盘选择器选择目标磁盘
3. **导航路径**：使用地址栏输入路径或点击面包屑导航
4. **文件操作**：右键菜单或工具栏按钮执行复制、粘贴、删除等操作

## 主要功能

### 1. 磁盘选择器

磁盘选择器提供现代化的磁盘切换界面：

- 显示磁盘名称、容量和可用空间
- 使用率进度条颜色指示（绿色 < 70%，黄色 70-90%，红色 > 90%）
- 支持键盘导航（上下箭头、Enter、Escape）
- 异步加载磁盘信息

**使用方法**：
1. 点击磁盘选择器按钮
2. 在弹出窗口中选择目标磁盘
3. 双击或按 Enter 确认

### 2. 地址栏

增强的地址栏提供多种导航方式：

#### 面包屑导航
- 显示当前路径的层级结构
- 点击任意路径段快速跳转

#### 路径自动补全
- 输入路径时自动显示补全建议
- 支持相对路径和绝对路径
- 补全延迟 < 300ms

#### 历史记录
- 自动记录访问过的路径
- 最近 20 条历史记录

#### 收藏夹
- 固定常用文件夹
- 快速访问收藏的路径

**快捷键**：
- `Ctrl + L`：切换到编辑模式
- `Escape`：返回导航模式

### 3. 文件列表视图

支持多种视图模式和图标尺寸：

#### 视图模式
- **详细信息**：显示文件名、大小、类型、修改日期等
- **图标**：大图标显示文件
- **缩略图**：图片文件显示预览缩略图
- **列表**：紧凑列表显示
- **平铺**：平铺卡片显示

#### 图标尺寸
- **小**：16x16 像素
- **中**：32x32 像素
- **大**：48x48 像素
- **特大**：64x64 像素

#### 虚拟化渲染
- 自动启用虚拟滚动，支持 10000+ 文件
- 仅渲染可见区域的文件项
- 滚动帧率 ≥ 30fps
- 内存占用优化

#### 缩略图功能
- 异步加载缩略图，不阻塞UI
- LRU缓存机制，减少重复加载
- 可配置缓存大小（默认100个）
- 缓存TTL（默认3600秒）

**视图操作**：
- 菜单栏 → 查看 → 选择视图模式
- 工具栏视图按钮
- 右键菜单 → 查看

**性能指标**：
- 文件列表首次渲染时间 < 500ms（1000项以内）
- 缩略图生成时间 < 100ms/项
- 视图模式切换不丢失选中状态和滚动位置

### 4. 快速访问

快速访问栏显示常用文件夹：

#### 功能
- 显示固定文件夹（置顶）
- 显示最近访问的文件夹
- 智能排序算法（综合考虑频率和时间衰减）

#### 操作
- **固定文件夹**：右键菜单 → 固定
- **取消固定**：右键菜单 → 取消固定
- **删除**：右键菜单 → 删除
- **清除历史**：右键菜单 → 清除最近记录

### 5. 主题切换

支持浅色和深色主题：

**切换方法**：
- 菜单栏 → 查看 → 主题
- 设置对话框 → 外观 → 主题

**主题特性**：
- 浅色主题：明亮背景，适合日间使用
- 深色主题：暗色背景，减少眼睛疲劳
- 跟随系统：自动跟随系统主题设置
- Mica材质效果：半透明背景（Windows 11）
- 主题切换动画：300ms淡入淡出

**性能**：
- 主题切换时间 < 300ms
- 无明显卡顿

## 设置

### 外观设置

- **文件夹字体**：设置文件夹名称字体和大小
- **文件名字体**：设置文件名称字体和大小
- **主题**：选择浅色、深色或跟随系统
- **圆角半径**：设置图标和选中效果的圆角大小
- **Mica效果**：启用/禁用半透明背景效果

### 视图设置

- **默认视图模式**：设置默认的文件列表视图模式
- **默认图标尺寸**：设置默认的图标大小
- **虚拟滚动**：启用/禁用虚拟化渲染
- **缩略图缓存大小**：设置缩略图缓存的最大数量

### 功能设置

- **记住最后浏览目录**：启动时恢复上次浏览的目录
- **自动扩展到当前文件夹**：导航时自动展开目录树
- **同步视图模式**：左右窗格使用相同的视图模式

## 常见问题

### Q: 如何切换左右窗格？

**A**: 点击目标窗格或使用 `Tab` 键切换焦点。

### Q: 为什么磁盘选择器显示"加载失败"？

**A**: 可能是权限不足或系统异常，请以管理员权限运行程序。

### Q: 如何固定文件夹到快速访问？

**A**: 右键点击文件夹 → 添加到快速访问，或在快速访问栏中右键 → 固定。

### Q: 主题切换后界面没有变化？

**A**: 部分窗口可能需要重启才能完全应用主题，建议重启程序。

### Q: 如何清除历史记录？

**A**: 在快速访问栏右键菜单中选择"清除最近记录"，或在设置中清除历史。

### Q: 文件列表加载很慢怎么办？

**A**: 
1. 确保启用了虚拟化渲染（默认启用）
2. 减少缩略图缓存大小
3. 使用详细信息视图而非缩略图视图
4. 检查是否有大量隐藏文件

### Q: 如何查看文件列表性能？

**A**: 
1. 查看状态栏的文件数量和加载时间
2. 查看日志文件中的性能记录
3. 使用开发者工具查看渲染帧率
