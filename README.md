- **绿色便携**：单文件 exe，无需安装

## 快速开始

### 普通用户

1. 前往 [Releases](https://github.com/tenlon-m/AFM-EST/releases) 下载最新安装包
2. 双击 `AFM-EST Setup.exe` 完成安装，或直接运行便携版 `AFM-EST.exe`
3. 完事，开用

### 从源码构建

```bash
git clone https://github.com/tenlon-m/AFM-EST.git
cd AFM-EST
pip install -r requirements.txt
pyinstaller AFM-EST.spec          # 生成 dist/AFM-EST.exe
```

打包 NSIS 安装包：`docs/打包说明.md`（参见 NSIS 脚本 `installer-AFM-EST.nsi`）。

## 一、软件简介

AFM-EST (Advanced File Manager with Enhanced Search & Transfer) 是一款现代化双窗口文件管理工具，深度整合文件浏览、高级搜索、多格式预览、压缩解压、跨协议传输（FTP / 点对点）、文件对比等核心功能，以 "高效操作、功能全覆盖、界面友好" 为设计理念，替代传统系统资源管理器，满足个人用户与专业办公场景下的多元化文件处理需求。

## 二、安装与运行

### 2.1 安装方式
- **单文件 exe**：直接运行 AFM-EST.exe 可执行文件
- **安装程序**：运行 AFM-EST Setup.exe，按照提示完成安装
- **便携版**：解压后直接运行 AFM-EST.exe

### 2.2 运行方式
1. 双击桌面快捷方式
2. 从开始菜单启动
3. 直接运行可执行文件

## 三、主界面介绍

AFM-EST 采用双窗口设计，主界面包含以下部分：

1. **菜单栏**：位于顶部，包含文件、编辑、查看、工具、传输、对比、帮助等菜单
2. **工具栏**：位于菜单栏下方，包含常用操作按钮和视图控制
3. **左右窗格**：两个独立的文件浏览窗口，支持独立操作
4. **功能面板**：位于右侧，包含搜索、对比、预览、传输等功能标签
5. **状态栏**：位于底部，显示文件信息、传输状态、系统资源等信息

## 四、基础操作

### 4.1 文件浏览

#### 4.1.1 导航操作
1. **地址栏**：
   - 直接输入路径按 Enter 键导航
   - 点击地址栏左侧的磁盘图标选择本地磁盘
   - 点击地址栏下拉箭头选择历史路径

2. **导航按钮**：
   - 后退：返回上一访问路径（快捷键：Alt+Left）
   - 前进：前进到下一访问路径（快捷键：Alt+Right）
   - 向上：返回上级目录（快捷键：Backspace）
   - 刷新：刷新当前目录文件列表（快捷键：F5）

#### 4.1.2 视图控制
1. **视图模式**：
   - 图标视图：显示大图标（快捷键：Ctrl+1）
   - 列表视图：显示紧凑列表（快捷键：Ctrl+2）
   - 详细信息：显示详细文件信息（快捷键：Ctrl+3）
   - 缩略图：显示图片缩略图（快捷键：Ctrl+4）
   - 平铺：显示大图标+详细信息（快捷键：Ctrl+5）

2. **分组显示**：
   - 无分组：不分组显示
   - 按类型：按文件类型分组
   - 按日期：按修改日期分组
   - 按大小：按文件大小分组

3. **显示隐藏文件**：
   - 按 Ctrl+H 切换显示/隐藏隐藏文件
   - 或通过"查看"菜单选择"显示隐藏文件"

### 4.2 文件操作

#### 4.2.1 基本操作
1. **选择文件**：
   - 单击选择单个文件
   - Ctrl+单击多选
   - Shift+单击连续选择
   - Ctrl+A 全选

2. **复制文件**：
   - 选中文件后按 Ctrl+C
   - 或右键菜单选择"复制"
   - 在目标位置按 Ctrl+V 粘贴

3. **移动文件**：
   - 选中文件后按 Ctrl+X
   - 或右键菜单选择"剪切"
   - 在目标位置按 Ctrl+V 粘贴

4. **删除文件**：
   - 选中文件后按 Del
   - 或右键菜单选择"删除"
   - 确认删除对话框后文件将被移至回收站

5. **永久删除**：
   - 选中文件后按 Shift+Del
   - 确认删除对话框后文件将被永久删除

6. **重命名文件**：
   - 选中文件后按 F2
   - 或右键菜单选择"重命名"
   - 输入新名称后按 Enter

7. **新建文件夹**：
   - 按 Ctrl+Shift+N
   - 或右键菜单选择"新建" > "文件夹"
   - 输入文件夹名称后按 Enter

8. **新建文件**：
   - 右键菜单选择"新建" > "文件"
   - 选择文件类型
   - 输入文件名称后按 Enter

#### 4.2.2 拖拽操作
1. **窗格内拖拽**：
   - 在同一窗格内拖拽文件可移动文件
   - Ctrl+拖拽可复制文件

2. **跨窗格拖拽**：
   - 在左右窗格之间拖拽文件实现快速复制/移动
   - 右键拖拽显示菜单可选择"复制到此处"、"移动到此处"、"创建快捷方式"

### 4.3 右键菜单

右键点击文件或文件夹，可显示以下菜单选项：

1. **基础操作**：打开、打开方式、预览
2. **文件操作**：剪切、复制、粘贴
3. **新建操作**：新建文件夹、新建文件
4. **文件管理**：删除、重命名、属性
5. **文件校验**：MD5、SHA-1、SHA-256哈希计算
6. **对比功能**：添加到左侧/右侧对比、对比选中文件
7. **压缩解压**：压缩到指定位置、解压到指定位置
8. **发送到**：收藏夹路径、系统发送到目标（Windows）
9. **批量操作**：批量重命名、文件编码转换、图片格式转换
10. **搜索功能**：启动搜索

## 五、高级功能

### 5.1 文件搜索

#### 5.1.1 快速搜索
1. 在地址栏输入关键字
2. 实时显示搜索结果
3. 按 Enter 键确认搜索

#### 5.1.2 高级搜索
1. 点击工具栏"搜索"按钮，打开搜索面板
2. 输入搜索关键字
3. 选择搜索目录
4. 设置搜索条件（文件类型、大小范围、修改日期等）
5. 点击"开始搜索"
6. 搜索结果可导出为 HTML 文件

### 5.2 文件预览

#### 5.2.1 自动预览
1. 选中文件后，功能面板自动切换到预览标签
2. 不同类型文件会显示不同的预览内容

#### 5.2.2 手动预览
1. 右键菜单选择"预览"
2. 或点击工具栏"预览"按钮

#### 5.2.3 支持格式
- **文本类**：TXT、LOG、代码文件等，支持语法高亮
- **图片类**：JPG、PNG、GIF、BMP等，支持缩放、旋转
- **音视频类**：MP3、MP4、AVI等，内置播放器
- **文档类**：DOC、DOCX、XLS、XLSX、PPT、PPTX、PDF等
- **压缩包类**：ZIP、7Z、TAR、RAR等，显示包内文件列表

### 5.3 文件对比

#### 5.3.1 文本文件对比
1. 选中两个文本文件
2. 点击工具栏"对比"按钮
3. 在对比面板中查看差异（新增绿色、删除红色、修改黄色）
4. 可导出差异报告

#### 5.3.2 文件夹对比
1. 选中两个文件夹
2. 点击工具栏"对比"按钮
3. 在对比面板中查看共同文件和差异文件
4. 可对差异文件执行复制/删除操作

### 5.4 压缩解压

#### 5.4.1 压缩文件
1. 选中文件或文件夹
2. 右键菜单选择"压缩到指定位置"
3. 选择压缩格式（ZIP、7Z、TAR等）
4. 设置压缩级别和密码（可选）
5. 选择保存位置
6. 点击"确定"开始压缩

#### 5.4.2 解压文件
1. 右键点击压缩包
2. 选择"解压到当前目录"或"解压到指定目录"
3. 如压缩包有密码，输入密码
4. 点击"确定"开始解压

## 六、网络传输

### 6.1 FTP/SFTP 传输

#### 6.1.1 连接服务器
1. 点击工具栏"传输"按钮，切换到 FTP 标签
2. 点击"新建连接"
3. 输入服务器地址、端口、用户名、密码
4. 选择协议（FTP、FTPS、SFTP）
5. 点击"连接"

#### 6.1.2 文件传输
1. 连接成功后，右侧窗格显示远程服务器文件
2. 在本地和远程窗口之间拖拽文件
3. 传输队列显示传输进度、速度和状态

### 6.2 点对点传输

#### 6.2.1 设备发现
1. 点击工具栏"传输"按钮，切换到 P2P 标签
2. 点击"扫描设备"，自动发现局域网内的设备

#### 6.2.2 建立连接
1. 选择目标设备
2. 点击"请求连接"
3. 对方确认连接请求

#### 6.2.3 文件传输
1. 连接建立后，选择要发送的文件
2. 点击"发送"
3. 对方确认接收
4. 查看传输进度和状态

## 十、常见问题与解决方案

### 10.1 无法启动程序
- 检查是否安装了必要的依赖
- 尝试以管理员身份运行
- 检查杀毒软件是否阻止了程序运行

### 10.2 无法显示某些文件
- 检查是否开启了"显示隐藏文件"选项
- 检查文件权限是否正确

### 10.3 压缩解压失败
- 检查文件是否损坏
- 对于 RAR 文件，确保安装了必要的依赖
- 检查磁盘空间是否充足

### 10.4 网络传输失败
- 检查网络连接是否正常
- 检查防火墙是否阻止了连接
- 对于 FTP/SFTP，检查服务器地址和凭证是否正确
- 对于 P2P，确保双方在同一局域网内

### 10.5 程序卡顿
- 关闭不需要的功能面板
- 对于大文件操作，耐心等待完成
- 检查系统资源使用情况
