通用场景优先级：UTF-8 > UTF-16 > GB18030 > GBK > Big5 > ISO-8859-1 > ASCII
中文专属场景优先级： GB18030 > GBK > GB2312 > Big5
老旧系统场景优先级：ISO-8859-1（Latin-1） > Shift_JIS > EUC-KR > ASCII
编码优先级的核心原则
兼容性优先：优先选择能覆盖所有目标字符的编码（如多语言文档必选 UTF-8）。
场景适配：中文 Windows 旧文档可选 GBK，编程 / 网页必选 UTF-8。
编码冲突的解决方法
若文件乱码，优先尝试 UTF-8 解码；中文文件可尝试 GBK/GB18030。
Unicode 编码的关系
UTF-8/UTF-16/UTF-32 是 Unicode 字符集的不同编码实现：
UTF-8：存储 / 传输首选；
UTF-16：内存处理首选；
UTF-32：几乎不用于文件存储。

创建编译脚本 build_kylin.sh：





 
#!/bin/bash
# AFM-EST 银河麒麟系统编译脚本

set -e

echo "=== AFM-EST 银河麒麟系统编译 ==="

# 检查Python版本
PYTHON_VERSION=$(python3 --version 2>&1 | awk '{print $2}')
echo "Python版本: $PYTHON_VERSION"

# 检查PyInstaller
if ! command -v pyinstaller &> /dev/null; then
    echo "安装PyInstaller..."
    pip3 install pyinstaller
fi

# 清理旧的编译文件
echo "清理旧的编译文件..."
rm -rf build/ dist/ *.spec

# 执行编译
echo "开始编译..."
pyinstaller --onefile \
    --icon=resources/icons/wjssdb.ico \
    --add-data "config:config" \
    --add-data "README.md:." \
    --name=AFM-EST \
    src/AFM-EST.py

# 检查编译结果
if [ -f "dist/AFM-EST" ]; then
    echo "✅ 编译成功！"
    echo "可执行文件: dist/AFM-EST"
    ls -lh dist/AFM-EST
    
    # 设置执行权限
    chmod +x dist/AFM-EST
    echo "✅ 已设置执行权限"
else
    echo "❌ 编译失败！"
    exit 1
fi

echo "=== 编译完成 ==="
